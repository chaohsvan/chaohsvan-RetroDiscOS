## 四个关键决策（都已记录在 `docs/decisions.md`）

| 编号 | 决策 | 影响 |
|---|---|---|
| D1 | 数字抓轨 → ALSA，不用光驱模拟输出 | 能拿 PCM 做频谱/seek/续播；代价是读取兼容性风险最高 |
| D2 | 不追 Bit-Perfect，音量用软件增益 | 实现简单、兼容任何声卡；音质非最优 |
| D3 | 纯键盘（evdev），不做鼠标 | 省掉整套指针逻辑；真机无桌面也能操作 |
| D4 | 托盘只能弹、不能收（固件限制） | 产品行为定型：弹出后手动推回，UI 不轮询自动关仓 |

## 主要风险

| 风险 | 等级 | 现状 |
|---|---|---|
| CD-DA 抓轨兼容性 | **高** | 未验证。这是唯一可能推翻 D1 的东西 |
| 中文字体 | 中 | 界面仅 ASCII，方案未定（扩字库 / FreeType） |
| 长时间稳定性 | 中 | 只有 ASan 下的短时观察，未做 24h |
| 功耗 | 低 | 未测，但 PRD 目标不高 |
| 双系统/EFI | 高但可控 | 全程未碰分区，只在虚拟机和笔记本上新装 Debian |
